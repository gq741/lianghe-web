# 螺旋影像 · 网页模型

双击 `dist/index.html` 即可离线运行，无需安装依赖。Chrome / Edge 需开启 WebGL 2。

## 操作

- 鼠标下滚：1 号头部向上顺时针运动，2 号尾部沿同一路径跟随。
- 鼠标上滚：原路反向；进度条、键盘上下键、触屏上下拖动同样有效。
- 「结构」显示深蓝正面和浅色背面；「影像」显示照片正面及同一照片的浅色镜像背面；「显示轨迹」显示固定路径。
- 「俯视检查」从 +Y 轴向下看，可检查顺时针方向。
- 「导入图片」选择最多 10 张，按选择顺序由头部至尾部排列；16:10 居中裁切。文件仅在浏览器内处理，不上传，刷新恢复示例。

## 参考分析

已提取并查看用户提供的两个视频：5.10 秒、9.70 秒。画面是绕纵轴盘旋的连续图片带，具有透视缩放、曲面弯曲和前后遮挡。

以随后补充的《丝带绕柱旋转上升_十帧运动轨迹图》为首要依据，使用约半圈的开放螺旋段，而不是完整圆环或多圈缠绕。初始为第 01 帧：下方、正前方留开口、右上为绿色 1 号头部、左下为红色 2 号尾部，主要显示浅色背面。运动一周后到达高处的第 10 帧。顺时针从柱顶向下观察。

示意图是透视示意而非带尺寸的三维工程图；当前按可观察的绕行关系和约半圈弧长建模，没有声称恢复图中未给出的精确三维尺寸。带长固定，10 张图片单排沿带面分布；图片比例约束决定带宽，因此不把图片横向压扁来模仿示意图中的竖向分段。

## 轴心标题

- 标题改为两行 `LIANGHE` / `AGENT`，使用清晰的透明字形纹理，位于世界坐标 `Z=0` 的轴心平面。
- AGENT 的固定纵向位置为 `Y=-0.08`，较原位置下移 0.10，以第 9 帧贴近丝带下沿；丝带和横向退场方向保持原样。
- 字形参与和丝带相同的深度测试：近处丝带遮住文字，文字遮住远处丝带。透明区域丢弃片元，字框不会挡住图像。
- 滚动上升时，`LIANGHE` 向右、`AGENT` 向左退出屏幕；位移使用滚动进度的三次方，前半程保留品牌辨识，到行程末端完整退场。反向滚动按同一进度原路返回，复位时回到轴心。
- 位移范围随视口宽度计算，而非固定像素值；减少动态效果模式继续遵循用户手动进度。

## 模型

中心线 `C(t) = (Rx cos(t+φ), Y0 + p t, Rz sin(t+φ))`。俯视时屏幕向下对应 +Z，因此增加 t 为顺时针。

- 左右半轴 `Rx=3.6`，前后半轴 `Rz=6.3`；前后轴为左右轴的 1.75 倍。
- 每圈上升 `PITCH=3.0`，从上一版 6.4 压缩垂直间距，保留压短后的螺旋形态。带仍为开放半圈，沿弧长均匀排列十张 16:10 图片。
- 主相机保持约 4.8° 的轻微仰视。桌面相机距离从 23 缩短至 16，横屏采用固定 30° 水平视场角，垂直视场角随窗口宽高比计算。按红圈参考的 43% 进度校准，丝带约占画面宽度 91%，左右各留约 4%～5%；1910×900 视口下左右边缘约为 x=86 / 1831。通过统一镜头缩放整体等比例放大，保留轨迹、图片比例和深度关系。窄屏平滑过渡到 46° 垂直视场角。近大远小关系保持；俯视检查仍使用原来的 36° 视场角。约 32.1% 进度时，尾部位于从头部起第 2 张照片下方；该对齐针对这个观察阶段，而非全程固定。没有单独掰弯头部，头尾仍沿同一条连续路径运动。
- 带长为椭圆螺旋一周弧长的一半，`WIDTH=LENGTH/16`，保留十个 16:10 图片位。
- 起始相位 `φ=-0.02`，头部初始高度 `Y0=-0.65`；页面和复位均从 0% 即第 01 帧开始。
- 每张图沿中心线的弧长为 `1.6 × WIDTH`；总长为 10 张图，不增减、不循环拼接。
- 材料坐标 `s∈[0,L]` 固定，`s=0` 为尾部，`s=L` 为头部。
- 滚动只改变沿路径的弧长相位 `q`。使用 4096 段弧长查找表，把材料坐标 `q+s` 反解为角度 `t`；避免椭圆弯头的图片被非均匀拉伸。
- 两端使用同一个相位变化，头尾间弧长恒定；整条带沿固定螺旋前进，不是原地旋转。
- 几何用 1000 段连续三角带，按实际椭圆切线建立带宽方向，深度缓冲处理遮挡。正反面由椭圆外法线与视线判定，影像模式中背面与正面共用同一纹理坐标，自然形成纸张反面的镜像，叠加 24% 浅蓝白色，保持可辨认的图像内容；结构模式仍保留纯色。
- 16:10 指曲面中心线长度与带宽比例；投影画面自然具有透视和曲面畸变。
- 每层纹理为 1600×1000，使用完整 mipmap、多级线性过滤及最高 8× 各向异性过滤（按硬件支持开启）。连续 UV 导数避免照片接缝误选模糊 mip 层；导入采用高质量等比例居中裁切，保留自然透视而非强行摊平曲面。
- 原生 WebGL 2，10 层独立纹理，不依赖 CDN；动画只在交互和状态变动时刷新，支持减少动态效果设置。

所有参数和着色器集中在单文件 `dist/index.html` 中。无轮询、无持续自动播放、无图片上传服务。
